# 오의진 포트폴리오

소재·계면·공정 분야의 연구 경험과 프로젝트를 소개하는 개인 포트폴리오 웹사이트입니다.

## 주요 내용

- **공정 최적화**: 공정 변수 분석 및 재현성 확보
- **계면 엔지니어링**: 표면 처리와 재료 조합을 통한 계면 결함 개선
- **데이터 분석**: Python과 Spotfire를 활용한 데이터 전처리 및 시각화
- **연구 프로젝트**: 2D/3D 페로브스카이트 계면 제어 및 박막 전사 공정

## 기술 구성

- HTML5
- CSS3
- JavaScript
- 반응형 웹 디자인

별도의 프레임워크나 라이브러리 없이 `index.html` 한 파일로 구성되어 있습니다.

## 실행 방법

저장소를 내려받은 후 `index.html` 파일을 브라우저에서 열면 됩니다.

```bash
git clone https://github.com/사용자이름/저장소이름.git
cd 저장소이름
```

또는 VS Code의 **Live Server** 확장 프로그램으로 실행할 수 있습니다.

## GitHub Pages 배포

1. GitHub 저장소의 **Settings**로 이동합니다.
2. 왼쪽 메뉴에서 **Pages**를 선택합니다.
3. **Build and deployment**의 Source를 `Deploy from a branch`로 설정합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
5. 잠시 후 생성된 웹사이트 주소로 접속합니다.

배포 주소 예시:

```text
https://사용자이름.github.io/저장소이름/
```

## 파일 구조

```text
.
├── index.html
└── README.md
```

## 수정할 부분

`index.html`에서 아래 내용을 본인 정보에 맞게 변경하면 됩니다.

- 자기소개 및 프로젝트 설명
- 이메일 주소: `your-email@example.com`
- GitHub 또는 기타 연락처 링크
- 프로젝트 성과와 기술 태그

## 특징

- PC와 모바일 화면에 대응하는 반응형 레이아웃
- 부드러운 스크롤과 카드 애니메이션
- 외부 이미지 및 패키지가 필요 없는 단일 페이지 구성
- GitHub Pages를 통한 무료 배포 가능
